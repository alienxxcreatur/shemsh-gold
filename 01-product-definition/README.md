## Gate 1 — معیار خروج

- [x] مسئله کاربر و مسئله بیزینس روشن و متصل به شواهد باشند.
- [x] چشم‌انداز و اصول برای تصمیم‌گیری طراحی قابل استفاده باشند.
- [x] مخاطبان و اولویت آن‌ها مشخص یا به‌عنوان سؤال باز ثبت شده باشد.
- [x] Jobهای اصلی و نگرانی‌های اعتماد ثبت شده باشند.
- [x] ارزش پیشنهادی و شواهد لازم برای اثبات آن روشن باشند.
- [x] اهداف کاربر، اهداف بیزینس و شاخص‌های موفقیت مرتبط باشند.
- [x] In scope، Out of scope، محدودیت‌ها و وابستگی‌ها ثبت شده باشند.
- [x] هیچ فرض مهمی به‌عنوان تصمیم قطعی ارائه نشده باشد.
- [x] مالک محصول نسخه مرحله را تأیید یا عبور مشروط را پذیرفته باشد.
