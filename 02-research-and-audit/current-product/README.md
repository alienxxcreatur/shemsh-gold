# محصول فعلی شمش

این پوشه آرشیو شواهد و ریسک‌های محصول قبلی است. طبق D-028، محصول فعلی مبنای طراحی Greenfield نیست و ممیزی کامل آن نیز شرط ادامه پروژه محسوب نمی‌شود. وجود یک رفتار در اینجا به‌معنای تأیید آن برای محصول هدف نیست.

- `shemsh-redesign-brief-inputs.md`: مشاهده‌ها و جزئیات خام
- `screenshots/`: شواهد تصویری محصول فعلی
- `inventory/`: Inventoryهای ساختاری و فایل‌های استخراج‌شده
- `product-audit.md`: ممیزی اولیه Legacy؛ فقط در صورت نیاز به شاهد مشخص تکمیل می‌شود
- `usability-issues.md`: مسائل اولویت‌بندی‌شده
- `observed-business-rules.md`: قوانین دیده‌شده ولی تأییدنشده

هر یافته باید به شاهد، تاریخ و سطح اطمینان متصل باشد.
