# مرحله ۲ — تحقیق هدفمند و ارزیابی

## هدف

ساخت ورودی کافی برای طراحی Greenfield شمش از طریق شناخت کاربران هدف، انتظارات بازار، قواعد رسمی و ریسک‌های مهم؛ بدون استفاده از محصول فعلی به‌عنوان مبنای فلوهای جدید.

**Business decision:** محصول فعلی فقط مرجع محدود برای ثبت تناقض‌ها و خطاهای واضح است. ممیزی کامل Legacy و تحلیل Baseline تاریخی، به‌دلیل نبود داده معتبر و جامعه کاربری قبلی کوچک، شرط عبور این مرحله نیستند. مرجع: D-028.

## ساختار

- `research-plan.md`: سؤال‌ها، روش‌ها و شکاف‌های تحقیق
- `evidence-and-research-gaps.md`: نگاشت تصمیم‌ها و سؤال‌های مرحله ۱ به شواهد، شکاف‌ها و اقدام بعدی
- `research-repository.md`: فهرست منابع و وضعیت اعتبار
- `current-product/`: شواهد خام و ثبت محدود ریسک‌های Legacy؛ نه مبنای طراحی هدف
- `competitors/`: گزارش هر رقیب و سنتز رقابتی
- `competitors/binance/`: مسیر تکمیلی D-163 برای استخراج Flow-first زبان بصری و Patternهای بایننس و نگاشت کنترل‌شده آن‌ها به شمش

## Gate 2 — معیار خروج

- [x] تصمیم‌ها، فرض‌ها و سؤال‌های مهم مرحله ۱ به شواهد یا شکاف مشخص متصل باشند.
- [x] فرض‌های مربوط به کاربران هدف، Jobها و اعتماد به موضوعات قابل اعتبارسنجی تبدیل شده باشند؛ اجرای تست به مرحله وایرفریم/پروتوتایپ منتقل شده است.
- [x] سنتز یکپارچه چهار رقیب، انتظار بازار و فرصت تمایز را با معیارهای یکسان نشان دهد.
- [x] قوانین مشاهده‌شده از قوانین تأییدشده جدا باشند.
- [x] شکاف‌های قواعد رسمی مالی، حقوقی، فنی و عملیاتی ثبت شده باشند.
- [x] ریسک‌ها و تناقض‌های واضح محصول قبلی ثبت شده باشند؛ Inventory یا ممیزی کامل آن الزامی نیست.
- [x] فرصت‌های رقابتی به تقلید مستقیم یا قانون قطعی شمش تبدیل نشده باشند.

## وضعیت

🟡 **Sufficient to proceed** — ورودی لازم برای مدل محصول فراهم و شکاف‌ها ثبت شده‌اند؛ تحقیق تازه به‌صورت موردی و اعتبارسنجی اصلی در مرحله وایرفریم/پروتوتایپ انجام می‌شود. مرجع D-032.

مسیر D-163 یک تحقیق تکمیلی برای مرحله ۷ است و Gate 2 را باز نمی‌کند. وضعیت داخلی آن `Sufficient to start extraction` است؛ رفتار بایننس فقط پس از Evidence، تکرار، Counter-example و نگاشت به شمش می‌تواند Candidate طراحی شود.
