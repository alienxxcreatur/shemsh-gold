# آرشیو

اسناد یا خروجی‌هایی که جایگزین شده‌اند به این پوشه منتقل می‌شوند؛ حذف نمی‌شوند.

برای هر مورد ثبت کنید:

- مسیر قبلی
- تاریخ آرشیو
- دلیل آرشیو
- سند جایگزین
- تصمیم مرتبط

منابع خام تحقیق و دارایی‌های برند صرفاً به‌دلیل قدیمی بودن به آرشیو منتقل نمی‌شوند؛ آن‌ها در پوشه تخصصی خود باقی می‌مانند و برچسب Legacy می‌گیرند.
