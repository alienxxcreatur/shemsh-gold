## ۵. قرارداد Component

| داده/اقدام | Component | رفتار ضروری |
|---|---|---|
| موبایل | Input با Label ثابت، `type=tel` و `inputmode=numeric` | نرمال‌سازی ارقام؛ Error زیر فیلد |
| رمز ورود | Password Input + Show/Hide | `autocomplete=current-password`، Paste و Password Manager مجاز |
| ساخت/بازیابی رمز | یک Password Input + آیکن چشم + چک‌لیست زنده Requirement | `autocomplete=new-password`؛ هرکدام از سه شرط طول/حرف/عدد هنگام تحقق Check می‌خورند؛ بدون Confirm تکراری؛ سقف فنی در متن UI نیست |
| فراموشی رمز | Text button با هدف لمسی ۴۸px | از صفحه رمز به OTP؛ Label روشن |
| OTP | یک Input معنایی و شش خانه بصری | `one-time-code`، Paste/Autofill، Auto-submit، پاک‌سازی Error/Expiry/Resend |
| تاریخ تولد | Trigger + Bottom Sheet شمسی | سه Wheel مستقل Scrollable، Snap، تاریخ واقعی و CTA تأیید؛ Blur فقط روی لبه و بخشی از دورترین آیتم بالا/پایین |
| کد ملی | Input عددی ده‌رقمی | Label ثابت، Error نزدیک فیلد، عدم Persist |
| کد معرف | Disclosure اختیاری | روی CTA یا KYC اثر ندارد |
| CTA | Button تمام‌عرض ۵۲px | Loading ثابت، Double-submit بسته، Disabled واقعی |
| Toast | Feedback گذرا در خانه | Success بدون Screen واسط؛ `aria-live=polite` |

## ۶. State و Recovery

| بخش | State | رفتار و Recovery |
|---|---|---|
| تشخیص موبایل | Loading/Failed | CTA Loading؛ Retry با حفظ موبایل |
| رمز ورود | Wrong | رمز پاک، موبایل حفظ، Focus رمز و CTA بازیابی |
| رمز ورود | Service/Offline | پیام نزدیک CTA، Retry؛ رمز خام Persist نشود |
| OTP | Invalid/Expired | کد پاک، Focus حفظ، پیام نزدیک گروه و Resend |
| OTP | Resend | کد قبلی باطل، خانه‌ها پاک، تایمرها Restart |
| ساخت رمز | Short/Common/Too long | Requirement مشخص و Error همان فیلد؛ OTP دوباره لازم نیست |
| ساخت Credential | Failed | Retry همان مرحله تا اعتبار جریان؛ در انقضا OTP تازه |
| Auth | Success | Signup مستقیم KYC؛ سایر مسیرها مستقیم خانه؛ Toast کوتاه |
| KYC | Invalid/Mismatch | Error نزدیک فیلد/فرم و اصلاح همان صفحه |
| KYC | Under 18 | پیام مستقل، قفل مالی و CTA خانه؛ Retry بی‌فایده نمایش داده نشود |
| KYC | Service/Offline | فرم حفظ، Retry یا بعداً به خانه |
| KYC | Success | مستقیم خانه با Toast |
| Session | Expired | ورود موبایل/رمز و خانه؛ بدون بازگشت Context |

## ۷. ممیزی پیش‌دستانه

- صفحه موبایل فقط «ادامه» دارد؛ قبل از تشخیص وضعیت حساب، «دریافت کد» یا «ورود با رمز» فرض نمی‌شود.
- پاسخ تشخیص حساب نباید در متن خطا امکان Enumeration شماره‌ها را افزایش دهد.
- رمز هرگز در URL، Analytics، Local Storage یا Log قرار نمی‌گیرد.
- Show/Hide هدف لمسی و Accessible label مستقل دارد و Layout را جابه‌جا نمی‌کند.
- Password Manager و Paste مسدود نمی‌شوند.
- OTP فقط در سه Context مصوب نمایش داده می‌شود؛ ورود روزمره یا انقضای نشست OTP ندارد.
- Resend در ۶۰ ثانیه فعال می‌شود؛ این انتخاب با هزینه SMS و زمان تحویل متناسب است.
- KYC پس از Signup جدید مستقیم باز می‌شود؛ در سایر Authها Home Card وضعیت احراز را بدون Modal مزاحم نشان می‌دهد.
- حالت زیر ۱۸ سال با Mismatch یکی نیست و متن آن حساب را «مسدود» معرفی نمی‌کند.
- پس از رسیدن به ۱۸ سال CTA تلاش دوباره KYC در خانه/پروفایل قابل دسترسی است.
- تمام صفحات روی ۳۲۰/۳۷۵/۴۳۰، Landscape، Keyboard باز، متن بزرگ، Screen Reader و Reduced Motion تست می‌شوند.

## ۸. سناریوهای Prototype

1. کاربر دارای رمز: موبایل نمونه ← رمز صحیح ← خانه.
2. کاربر جدید: موبایل نمونه ← OTP صحیح ← ساخت رمز ← KYC ← خانه.
3. کاربر قدیمی فاقد رمز: همان مسیر OTP با کپی Migration ← ساخت رمز ← خانه.
4. فراموشی رمز: موبایل ← OTP ← رمز تازه ← خانه.
5. رمز نادرست و Recovery.
6. OTP اشتباه، منقضی و Resend پس از ۶۰ ثانیه.
7. KYC موفق از خانه و بازگشت خانه.
8. KYC زیر ۱۸ سال با حفظ حساب و قفل عملیات مالی.
9. KYC Mismatch و Service Error.
10. نشست منقضی، ورود با رمز و خانه.
