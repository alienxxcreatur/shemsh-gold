# مدل ناوبری

## تصمیم‌های لازم

- مقصدهای سطح اول موبایل، حداکثر پنج مورد
- رفتار Sidebar یا Navigation در نمایشگر بزرگ
- تفاوت Navigation سایت عمومی و محصول
- جایگاه خدمات ثانویه
- رفتار Back و حفظ فیلتر/ورودی/Scroll
- Deep Link اعلان و رسید
- دسترسی کاربر احرازنشده

|---|---|---|---|---|---|
| Primary |  |  |  |  | Bottom nav / Sidebar |
| Secondary |  |  |  |  | Hub / Menu |
| Contextual |  |  |  |  | CTA / Link |

## قواعد کیفیت

- مقصد سطح اول فقط کار سطح اول باشد.
- آیکن بدون Label در ناوبری اصلی استفاده نشود.
- مسیر Back قابل پیش‌بینی باشد و وضعیت قبلی را حفظ کند.
- قابلیت غیرفعال بدون توضیح پنهان یا بی‌اثر نباشد.
