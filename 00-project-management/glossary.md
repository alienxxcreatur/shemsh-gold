# واژه‌نامه و برچسب‌های پروژه

## برچسب شواهد

- **Observed fact / واقعیت مشاهده‌شده:** مستقیماً در محصول، داده، سند رسمی یا تحقیق دیده شده است.
- **Business decision / تصمیم بیزینس:** توسط صاحب اختیار تأیید شده و مبنای طراحی است.
- **Design assumption / فرض طراحی:** پاسخ موقت و قابل بازبینی برای ادامه کار.
- **Open question / سؤال باز:** اطلاعات یا تصمیمی که هنوز وجود ندارد.
- **Risk / ریسک:** موضوعی که می‌تواند به اعتماد، کاربردپذیری، زمان یا عملیات آسیب بزند.
- **Design inference / استنباط طراحی:** برداشت تحلیلی از شواهد، نه واقعیت قطعی.

## واژه‌های کلیدی

- **Capability Map:** نقشه تمام توانمندی‌های سطح بالای محصول.
- **Information Architecture:** ساختار محتوا، صفحات و رابطه آن‌ها.
- **User Flow:** مسیر مرحله‌به‌مرحله کاربر برای رسیدن به یک هدف.
- **State Matrix:** فهرست حالت‌های موفق، انتظار، خالی، خطا، محدود و بازیابی.
- **Vertical Slice:** طراحی یک تجربه از نقطه ورود تا نتیجه، به‌جای طراحی پراکنده چند صفحه.
- **Gate:** معیار رسمی عبور از یک مرحله به مرحله بعد.
- **Source of Truth:** سند رسمی و یگانه برای یک نوع اطلاعات.
