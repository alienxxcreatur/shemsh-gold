## روش

1. یک ردیف در `flow-index.md` ایجاد شود.
2. با `flow-template.md` سند فلو ساخته شود.
3. قوانین رسمی و سؤال‌های باز لینک شوند.
4. تمام حالت‌ها در `state-matrix.md` پوشش داده شوند.
5. کپی، اعلان و پشتیبانی Contextual ثبت شوند.
