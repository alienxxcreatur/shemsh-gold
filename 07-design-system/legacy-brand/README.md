# دارایی‌های برند قبلی

این پوشه شامل گایدلاین، لوگوها و فونت‌های برند قبلی است و برای تحقیق و ارزیابی نگهداری می‌شود.

در فاز ۱ مرحله ۷، فایل `shemshbrand guideline.V.1.pdf` به‌طور کامل ممیزی و به‌عنوان ورودی Candidate پذیرفته شد. نتیجه انتقال رنگ، فونت و قواعد لوگو در `../foundations/legacy-brand-candidate-map.md` ثبت شده است؛ این پذیرش به معنی `Stable` شدن مقادیر قدیمی نیست.

هیچ دارایی این پوشه بدون بررسی موارد زیر وارد سیستم طراحی جدید نشود:

- اعتبار و نسخه رسمی
- مجوز استفاده فونت و فایل‌ها
- تناسب با جهت «مطمئن، روزمره، کمی پریمیوم»
- خوانایی فارسی و اعداد مالی
- عملکرد در Light/Dark و اندازه‌های مختلف
- هماهنگی با لوگو و هویت تأییدشده جدید
