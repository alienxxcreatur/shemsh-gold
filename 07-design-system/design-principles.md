# اصول طراحی بصری و تعاملی

1. **دقت مالی قبل از تزئین:** عدد، واحد، زمان و وضعیت باید سریع اسکن شوند.
2. **طلایی کنترل‌شده:** رنگ طلایی برای هویت و تأکید محدود استفاده شود، نه تمام سطح‌ها.
3. **اعتماد از شواهد:** مجوز، رسید، منبع قیمت و فرایند واقعی جای ادعای تبلیغاتی را بگیرند.
4. **یک CTA اصلی:** هر صفحه یک اقدام اصلی واضح داشته باشد.
5. **حالت‌ها قابل تشخیص:** Disabled، Pending، Error و Success فقط با رنگ منتقل نشوند.
6. **حرکت معنادار:** Motion علت و معلول، سلسله‌مراتب یا تداوم را توضیح دهد.
7. **کیفیت آرام:** فاصله، تایپوگرافی، کپی و ثبات جزئیات حس پریمیوم را بسازند.
