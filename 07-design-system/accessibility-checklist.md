# چک‌لیست دسترس‌پذیری

- [ ] کنتراست متن عادی حداقل 4.5:1 است.
- [ ] رنگ تنها وسیله انتقال وضعیت نیست.
- [ ] تمام کنترل‌ها Label قابل فهم دارند.
- [ ] ترتیب Focus با ترتیب بصری یکی است.
- [ ] فرم‌ها Label پایدار، Hint و Error نزدیک فیلد دارند.
- [ ] Touch targetها حداقل استاندارد را رعایت می‌کنند.
- [ ] بزرگ‌نمایی متن و Dynamic Type چیدمان را نمی‌شکند.
- [ ] Reduced Motion پشتیبانی می‌شود.
- [ ] وضعیت Selected، Disabled، Expanded و Error اعلام می‌شود.
- [ ] نمودار جایگزین متنی و مقدار دقیق دارد.
- [ ] Back، Cancel و خروج امن از Modal وجود دارد.
- [ ] Light و Dark مستقل بررسی شده‌اند.
